# Deprem Öncesi Hazırlık Simülasyonu

Unity ile geliştirilmiş, tek oyunculu bir 3D afet hazırlığı oyunudur. Oyuncu evdeki riskleri azaltır, afet çantası malzemelerini toplar ve aile buluşma planını tamamlar.

## Platform

Windows 64-bit.

## Oyunu çalıştırma

1. Teslim edilen oynanabilir oyun ZIP dosyasını tamamen çıkarın.
2. Klasördeki “DEPREM ÖNCESİ HAZIRLIK SİMİLASYONU.exe” dosyasını açın.
3. Uygulamayı yanındaki klasör ve DLL dosyalarından ayırmayın.

Oynamak için Unity kurulumu gerekmez. Bu repo kaynak projeyi içerir; oynanabilir Windows sürümü ayrıca teslim edilir.

## Kontroller

| Tuş | İşlev |
| --- | --- |
| WASD / Yön tuşları | Hareket |
| Fare | Etrafa bakma |
| E / Sol tık | Etkileşim |
| Sol Shift | Hızlı yürüme |
| Q | Hazırlık ve sonuç görünümü arasında geçiş |
| TAB | Görev günlüğü |
| H | İpucu |
| F | Eğitim fenerini açma/kapatma |
| ESC | Duraklatma / açık ekranı kapatma |

## Amaç

Evdeki altı riski azaltın, dokuz örnek malzemeyi toplayarak afet çantasını hazırlayın ve aile buluşma planını tamamlayın. Sekiz hazırlık adımını bitirdikten sonra Q ile sonuç görünümünü kontrol edin ve giriş koridorundaki terminalden tatbikatı tamamlayın.

İlerleme otomatik kaydedilir. “Devam et” kayıtlı hazırlıkları yükler; “Oyna” yeni kayıt başlatır.

## Kaynak projeyi açma

1. Repoyu indirin veya klonlayın.
2. Unity Hub üzerinden Assets, Packages ve ProjectSettings klasörlerinin bulunduğu proje klasörünü ekleyin.
3. ProjectSettings/ProjectVersion.txt dosyasında belirtilen Unity Editor sürümünü kullanın.
4. Assets/Keske/Scenes/KeskeBirlesik.unity sahnesini açıp Play düğmesine basın.

## Bilgilendirme

Oyundaki sonuçlar eğitim amaçlı hazırlanmış örneklerdir; gerçek deprem veya bina güvenliği hesabı değildir.
